# v0.5.1 — Clearer execution charts

Execution charts start with your trend and one Tournament reference. A shared
Chart references control lets you choose Diamond Slippi, Master Slippi,
SSBMStats Community, Tournament, Pro Tournament, or no references across the
rolling execution, move, and action charts. Table highlighting remains a
separate choice. Missing measurements stay unavailable without substituting
another sample.

Long chart explanations and source details are expandable. The rolling window,
selected sample scope, loading failures, and missing references remain visible.

This is a presentation update. Replay analysis remains at stats version 10;
the chart changes do not require another replay refresh. Existing records from
before v0.5.0 can still need the one-time parser update described in the
[v0.5.0 notes](v0.5.0.md).
